# পোস্ট কপি: ৪টা Reel (claude-reel-1 … 4)

ফাইল: `F:\Video Create Renders\claude-reels\reel-1` … `reel-4` (প্রতিটায় 9:16 ভিডিও আর কভার ছবি)

**কোথায় কী দেখাবে (আপনার নির্দেশমতো):**
- Facebook Reels → Facebook-এ আপনার পেজের পুরো ভিডিও (লিংক প্রথম কমেন্টে)
- Instagram Reels → YouTube-এর পুরো ভিডিও (লিংক Bio-তে; Instagram-এ ক্যাপশন বা কমেন্টের লিংকে ক্লিক হয় না)
- YouTube Shorts → YouTube-এর পুরো ভিডিও (আপলোডের সময় **Related video**-তে পুরো ভিডিওটা বেছে দিন; Short-এর নিচে ক্লিক করার লিংক আসে)

**কখন পোস্ট:** আগে পুরো ভিডিও (YouTube + Facebook পেজ)। তারপর দিনে একটা Reel: Reel ১ → Reel ৪ → Reel ৩ → Reel ২। এক দিনে সব না দিলে প্রতিটা Reel আলাদা করে মানুষের কাছে যাওয়ার সুযোগ পায়। সময়: রাত ৮–১০টার দিকে অনেক পেজ ভালো ফল পায়, তবে আপনার Page Insights-এ "কখন ফলোয়াররা অনলাইনে থাকে" দেখে ঠিক করুন।

**প্রথম কমেন্ট (Facebook, প্রতিটা Reel-এ নিজে কমেন্ট করুন):**

```

```
