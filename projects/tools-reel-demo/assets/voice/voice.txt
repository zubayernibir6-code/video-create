Don't build with Claude Code until you've installed these five free tools. The first is Context 7, from Upstash. It pulls the current docs for any library you use, so Claude stops writing code that broke two versions ago. Fresh docs every time. The second is Firecrawl. Let's Claude read any website. Docs, blogs, and pricing pages is clean text, so research takes seconds, not hours. The third is the GitHub MCP server. It lets Claude open issues, write the fix, review the pull request, and merge it so one prompt ships the whole change. The fourth is Playwright MCP from Microsoft. Click through your login, check out and search like a real user so every flow is tested before you ship. And the fifth is Chrome DevTools MCP from the Chrome team at Google. It opens your app in a real Chrome, reads the red errors in the console, and fixes them itself. Comment tools, and I'll send you one link with all five.
