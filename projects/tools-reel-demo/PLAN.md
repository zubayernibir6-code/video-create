## স্ক্রিপ্ট

১. (০:০০.০) Don't build with Claude Code until you've installed these five free tools.
২. (০:০৩.১) The first is Context7, from Upstash.
৩. (০:০৫.৬) It pulls the current docs for any library you use, so Claude stops writing code that broke two versions ago. Fresh docs, every time.
৪. (০:১২.৩) The second is Firecrawl.
৫. (০:১৩.৩) It lets Claude read any website, docs, blogs and pricing pages as clean text, so research takes seconds, not hours.
৬. (০:১৯.২) The third is the GitHub MCP server.
৭. (০:২১.৪) It lets Claude open issues, write the fix, review the pull request and merge it, so one prompt ships the whole change.
৮. (০:২৭.০) The fourth is Playwright MCP, from Microsoft.
৯. (০:২৯.১) It clicks through your login, checkout and search like a real user, so every flow is tested before you ship.
১০. (০:৩৪.৪) And the fifth is Chrome DevTools MCP, from the Chrome team at Google.
১১. (০:৩৮.৬) It opens your app in a real Chrome, reads the red errors in the console and fixes them itself.
১২. (০:৪৩.১) Comment TOOLS, and I'll send you one link with all five.
