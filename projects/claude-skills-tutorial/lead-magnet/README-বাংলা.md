# নিজের প্রথম Claude স্কিল: বাংলা টেমপ্লেট

এই প্যাকে দুটো জিনিস আছে:

- `my-first-skill.zip`: খালি টেমপ্লেট। নিজের কাজের কথা লিখে আপলোড করবেন।
- `monthly-report.zip`: পূরণ করা উদাহরণ (ভিডিওতে যেটা দেখানো হয়েছে)। সরাসরি আপলোড করে চালিয়ে দেখতে পারেন।

## ১. টেমপ্লেট পূরণ করুন

1. `my-first-skill.zip` আনজিপ করুন (ফাইলে রাইট-ক্লিক → Extract All)।
2. ভেতরের `my-first-skill` ফোল্ডারে `SKILL.md` ফাইলটা Notepad দিয়ে খুলুন।
3. উপরের `description` লাইনে এক-দুই লাইনে লিখুন: স্কিলটা কী করে, আর কখন কাজে লাগবে। এটাই সবচেয়ে জরুরি লাইন।
4. নিচের অংশগুলোতে নিজের কাজের নিয়ম লিখুন: ধাপ, ফরম্যাট, উদাহরণ, যা কখনো করবে না।
5. নাম বদলাতে চাইলে `name` লাইন আর ফোল্ডারের নাম দুটোই একসাথে বদলান। শুধু ছোট হাতের ইংরেজি অক্ষর, সংখ্যা আর হাইফেন (-), ৬৪ অক্ষরের মধ্যে। নামে "claude" বা "anthropic" শব্দ রাখা যাবে না।

## ২. আবার ZIP করুন

- ফোল্ডারটার উপর রাইট-ক্লিক → Send to → Compressed (zipped) folder।
- মনে রাখবেন: ZIP-এর ভেতরে পুরো ফোল্ডার থাকতে হবে, শুধু SKILL.md ফাইল নয়।

## ৩. Claude-এ চালু করুন

1. Claude-এ Settings → Capabilities খুলুন। সেখানে "Code execution and file creation" চালু করুন (নতুন ডিজাইনে নাম "Create and edit files")।
2. Customize → Skills খুলুন।
3. "+" বোতাম → "Create skill" → "Upload a skill" → আপনার ZIP ফাইলটা দিন।
4. তালিকায় স্কিলটা এলে পাশের সুইচটা অন আছে কি না দেখুন।

মেনুর নাম অ্যাপের সংস্করণভেদে একটু আলাদা হতে পারে।

## ৪. পরীক্ষা করুন

নতুন চ্যাট খুলে কাজটা সাধারণভাবে বলুন। যেমন: "মার্চ মাসের ফি রিপোর্ট বানাও"।
Claude স্কিলটা না খুললে বলুন: "আমার monthly-report স্কিল দিয়ে বানাও"। তারপর description লাইনটা আরও পরিষ্কার করে লিখুন।

## সাবধানতা

স্কিল প্রোগ্রাম চালাতে পারে। অচেনা জায়গা থেকে পাওয়া স্কিল বসানোর আগে ভেতরের ফাইলগুলো খুলে দেখে নিন।

তথ্যের সূত্র: Claude-এর সাহায্য পাতা "Use skills in Claude" (support.claude.com) আর Agent Skills ডকুমেন্টেশন (platform.claude.com), ২ নভেম্বর ২০২৬-এ পড়া।
