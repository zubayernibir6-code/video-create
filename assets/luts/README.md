# রঙের ফিল্টার (LUT) — ৩টা বসানো আছে ✅

LUT মানে **Look-Up Table** — রঙের একটা ছক। ভিডিওর প্রতিটা রং কোন রঙে বদলাবে, সেটা এই
ফাইলে লেখা থাকে। সিনেমায় যে "রঙের মেজাজ" দেখেন, সেটা এভাবেই বসানো হয়।

| ফাইল | চেহারা | কোথায় লাগে |
| --- | --- | --- |
| `teal-orange-blockbuster.cube` | ছায়া নীলচে, আলো কমলাটে | সিনেমার মতো ঝকঝকে ভাব |
| `bleach-bypass.cube` | রং কমে যায়, কনট্রাস্ট বাড়ে | কড়া, রুক্ষ, সাহসী ভাব |
| `film-fade.cube` | ম্লান, গরম, কালো রং হালকা | পুরোনো ফিল্মের নরম ভাব |

প্রতিটা ফাইল ৩৩×৩৩×৩৩ মাপের, ৯৪৮ KB।

---

## 💰 লাইসেন্স — নিরাপদ

এই তিনটা ফাইল **কোথাও থেকে নামানো হয়নি**। `media-use` স্কিলে দেওয়া কিছু সংখ্যা
(কনট্রাস্ট, স্যাচুরেশন, ছায়া-আলোর ঝোঁক) থেকে **আপনার কম্পিউটারেই হিসাব করে তৈরি**
করা হয়েছে — ইন্টারনেট লাগেনি, কোনো অ্যাকাউন্ট লাগেনি, কারও বানানো ফাইল কপি করা হয়নি।

তাই বাণিজ্যিক কাজে ব্যবহারে কোনো বাধা নেই।

## 🧪 যাচাই করা হয়েছে (১১ সেপ্টেম্বর ২০২৬)

একটা আসল ১৯২০×১০৮০ ফ্রেমে তিনটাই বসিয়ে রঙের পরিবর্তন **মেপে** দেখা হয়েছে:

| ফিল্টার | উজ্জ্বলতা | রঙের ঝোঁক |
| --- | --- | --- |
| মূল ছবি | ২২১.৫ | — |
| teal-orange-blockbuster | ২৩১.১ | সামান্য ঠান্ডা |
| bleach-bypass | ২৩১.২ | ধূসরের দিকে (রং কমেছে) |
| film-fade | ১৯৪.৮ | গরম দিকে, ম্লান |

তিনটাই যেমন কাজ করার কথা, তেমনই করছে।

## 🔧 কীভাবে ব্যবহার করবেন (কারিগরি)

### তৈরি ভিডিওতে বসাতে

```bash
cd "E:/Video Create/assets/luts"
ffmpeg -i input.mp4 -vf "lut3d=file='film-fade.cube'" -c:a copy output.mp4
```

> ⚠️ **`cd` করে LUT ফোল্ডারে ঢুকে কমান্ডটা চালান।** Windows-এ পুরো পথ (`E:\...`)
> FFmpeg-এর ফিল্টারে লিখলে কোলন আর ব্যাকস্ল্যাশ নিয়ে ঝামেলা হয়। আপেক্ষিক নাম নিরাপদ।

### অর্ধেক মাত্রায় বসাতে (বেশিরভাগ সময় এটাই ভালো)

```bash
ffmpeg -i input.mp4 -filter_complex "[0:v]lut3d=file='film-fade.cube'[g];[0:v][g]blend=all_mode=normal:all_opacity=0.6" -c:a copy output.mp4
```

`all_opacity` বদলে ০.৩ থেকে ০.৮ করে দেখুন — পুরো ১.০ প্রায়ই বেশি হয়ে যায়।

### শুধু একটা ছবিতে পরখ করতে

```bash
cd "E:/Video Create/assets/luts"
ffmpeg -y -i test.png -vf "lut3d=file='bleach-bypass.cube'" test-graded.png
```

## ➕ আরও লুক দরকার হলে

`media-use` স্কিলে মোট **৩টাই** লুক আছে — এগুলোই বসানো হয়েছে। নতুন লুক লাগলে
দুটো পথ:

1. **নিজের সংখ্যা দিয়ে বানানো** (ইন্টারনেট লাগে না, লাইসেন্স পরিষ্কার):
   `node <media-use>/scripts/resolve.mjs --type lut --intent "<নাম>" --project <ফোল্ডার> --local-only --params '{"contrast":0.2,"saturation":-0.3,...}'`
2. **বাইরে থেকে `.cube` নামানো** — ⚠️ তখন **লাইসেন্স যাচাই করতেই হবে**, কারণ
   আপনি বিক্রি করবেন। অনেক ফ্রি LUT আসলে "ব্যক্তিগত ব্যবহারের জন্য"।

> **মনে রাখুন:** এই ভিডিও প্রজেক্টগুলোতে এখনো কোনো আসল ছবি বা ফুটেজ নেই — সব লেখা
> আর রং দিয়ে বানানো। LUT আসল কাজে লাগবে যখন সত্যিকারের ছবি বা ভিডিও ক্লিপ ব্যবহার
> করবেন। তাই এটা এখন **ভবিষ্যতের জন্য তৈরি রাখা**, এখনই দরকার নেই।
