# মিউজিক ফোল্ডার — এখনো খালি

এখানে ব্যাকগ্রাউন্ড মিউজিকের ফাইল রাখতে হবে (`.mp3`)।

---

## ⚠️ যা জেনে রাখা দরকার

**Pixabay-এর API দিয়ে মিউজিক নামানো যায় না।** ওদের API শুধু ছবি আর ভিডিও দেয় —
মিউজিকের কোনো ব্যবস্থা নেই (যাচাই করা হয়েছে ১০ সেপ্টেম্বর ২০২৬)।
তাই **API key নেওয়ার দরকার নেই** — ওটা কোনো কাজে লাগবে না।

মিউজিক নিজে হাতে নামাতে হবে। কাজটা সহজ।

---

## 🎵 কীভাবে মিউজিক যোগ করবেন (৫ মিনিট)

1. ব্রাউজারে যান: **`pixabay.com/music/`**
2. উপরে ডানে **Join** দিয়ে একটা ফ্রি অ্যাকাউন্ট খুলুন (ডাউনলোড করতে লগইন লাগে)।
   কোনো টাকা লাগে না, কার্ড লাগে না।
3. পছন্দের গান খুঁজুন। কাজে লাগে এমন খোঁজার শব্দ:
   - `corporate` — কর্পোরেট/প্রোডাক্ট ভিডিওর জন্য
   - `cinematic` — গম্ভীর, সিনেমার মতো
   - `uplifting` — আশাব্যঞ্জক, উজ্জ্বল
   - `ambient` / `calm` — শান্ত, লেখার নিচে বাজার জন্য
   - `technology` / `inspiring corporate` — সফটওয়্যারের প্রোমোর জন্য
4. **Download** চাপুন, MP3 নামান।
5. ফাইলটা এই ফোল্ডারে রাখুন:
   `E:\Video Create\assets\music\`
6. নাম দিন সহজ করে — যেমন `corporate-calm.mp3`, `cinematic-build.mp3`
7. AI-কে বলুন **"মিউজিক রেখেছি"** — সে যাচাই করে তালিকায় যোগ করে দেবে।

**পরামর্শ:** শুরুতে ৪-৬টা গান নামান — একটা শান্ত, একটা উৎসাহী, একটা গম্ভীর,
একটা দ্রুত। বেশিরভাগ ভিডিওতে এতেই কাজ চলে যায়।

## 🔧 মিউজিক ভিডিওতে কীভাবে বসে (কারিগরি — AI-এর জন্য)

`index.html`-এ, দৃশ্যগুলোর পাশে (root-এর সরাসরি সন্তান হিসেবে):

```html
<audio id="bgm-bed" src="assets/music/corporate-calm.mp3"
       data-start="0" data-duration="30"
       data-track-index="9" data-volume="0.30"></audio>
```

- `id` **বাধ্যতামূলক** — না দিলে রেন্ডার নিঃশব্দ হবে, কোনো ভুলবার্তাও আসবে না
- গানের ফাইল ভিডিওর চেয়ে লম্বা হলে `data-duration` দিয়ে কেটে নেওয়া হয় — পরীক্ষা করে দেখা হয়েছে
- `data-volume` — কথার নিচে `0.10`-`0.15`, কথা না থাকলে `0.30`-`0.60`
- SFX-এর চেয়ে **নিচের** ট্র্যাক নম্বরে রাখুন (যেমন ৯, আর SFX ১০/১১)
- ফোল্ডারটা প্রজেক্টের ভিতরে **কপি** করতে হয় (ফন্ট ও js-এর মতোই)

পুরো প্রমাণ ও মাপা ফলাফল `CLAUDE.md`-এর ৪ঘ অংশে।
