# R4: Can the Video Create repo be sold? Licences, monetization routes, risks

Researched 2026-11-07. Not legal advice. Every claim carries a source URL. Items marked **[UNCERTAIN]** came from third-party blogs, conflicting sources, or could not be confirmed on an official page. Most price figures from aggregator blogs are seller-reported and disagree with each other, so re-check the vendor page before quoting a price to a client.

---

## 0. Bottom line (read this first)

1. **Selling the whole repo as-is is NOT clean.** Four things in it block a straight "sell the repo" move:
   - **Pixabay sound effects and music** are allowed in your videos, but you cannot sell or distribute them "on a Standalone basis" (unmodified, same form as on the site). A repo or pack that ships the raw mp3 files is the risky case. Fix: do not ship them, ship a script that fetches them, or ship only your own or CC0 sounds.
   - **GSAP**: free for commercial use (Webflow licence, effective 2025-04-30), but it bans use in tools that help users build visual animations without code in a way that competes with Webflow, and it says nothing clear about redistributing a copy. Fix: list `gsap` as an npm dependency and do not commit copies of the library into the sold repo.
   - **Piper voices**: each voice has its own licence; some are non-commercial. His Bengali voice must be checked file by file before any voice file is shipped or any Piper-voiced video is sold. **[UNCERTAIN: the bn_BD voice's MODEL_CARD was not found]**
   - **Google Gemini TTS and Lyria**: outputs are his to use, but SynthID is added to all audio, and the Gemini terms forbid using the service to build competing models. The output files (generated voice, music) must not be shipped as a "royalty-free asset library".
2. **Everything else is fine to bundle** with the right notices: HyperFrames (Apache-2.0), Three.js and Lottie (MIT), Lucide (ISC plus MIT for the Feather-derived icons), Noto Emoji (OFL for fonts, Apache-2.0 for images), SIL OFL fonts (bundled inside a larger product, never sold as the font alone).
3. **The thing worth selling is the know-how** (skills, guards, STYLE/LESSONS taste data, proven prompts, the plan gate), not the frameworks. The most realistic first income is a **productized service** (he makes the videos with the repo), then a **paid skill/prompt pack and course sold from a private marketplace or Gumroad-type shop**, then maybe a SaaS later.
4. **Do not name a product "Claude ..." or use the Claude/Anthropic logo.** Anthropic's trademark guidelines allow use only as Anthropic specifically permits, in materials it approves in advance.

### 1.2 Red flags, ranked

1. Pixabay raw sound files inside anything that is distributed or sold (high risk, easy fix).
2. Piper voices: unknown licence on the exact Bengali voice (high risk, easy to check, one file open away).
3. GSAP: do not make a tool where customers visually build animations; do not ship a copy of the library; accept that Webflow can amend terms (medium).
4. AI audio and images: SynthID stays; no stand-alone asset-library resale; no competing-model use of Gemini output (medium).
5. Product names and logos using Claude/Anthropic (medium, see section 3).
6. If a second person is ever hired and he uses Remotion: company licence from 4 people (low today).

## 2. Ways to monetize (2025-2026 facts)

### 2a. Selling Claude Code skills and plugins

- **Distribution is built in and free.** A plugin marketplace is just a git repo with `.claude-plugin/marketplace.json`; it "can be private", can list many plugins, and people add it with `claude plugin marketplace add <owner>/<repo>`. An org can require it on every machine. There is also a "Submit to Anthropic's directory" route for offering a plugin to everyone ([Claude Code docs](https://code.claude.com/docs/en/plugin-marketplaces), fetched 2026-11-07).
- **There is no official paid marketplace.** Reporting says the official marketplace is free, listing roughly 101 plugins in March 2026 and "hundreds" by May 2026, and the wider scene is "fragmented" ([ryandoser.com](https://ryandoser.com/claude-skills-marketplace/), [alexcloudstar.com](https://www.alexcloudstar.com/blog/claude-code-plugin-marketplace-skills-2026), search results 2026-11-07) **[UNCERTAIN: blogs, not Anthropic]**.
- **Free competition is huge.** One registry says it indexes 67,000+ skills ([claudskills.com](https://claudskills.com/skills/gumroad-seller/)) **[UNCERTAIN]**, and HyperFrames itself ships its skills free and has about 450 free blocks ([README](https://github.com/heygen-com/hyperframes)).

## 3. Risks

### 3.1 Open vs private (moat)

- **Frameworks are commodity:** HyperFrames, GSAP, FFmpeg, Piper are free and public; HyperFrames even ships free skills and 450 free blocks.
- **What is actually valuable and hard to copy:** (1) the 15+ skills with their routing (route.mjs, style codes TUT1/CP1/EXP1...); (2) the guards (plan-check, preflight, design-lint, qc, glitch-scan) that encode mistakes already paid for; (3) STYLE.md and LESSONS.md, his client taste data in Bengali; (4) proven Bengali typography/caption rules; (5) the prompt packs and the workflow that a non-coder can run end to end; (6) his cloned voice and his audience.
- **Skills are copyable.** A skill is plain text; any buyer can redistribute it, and no DRM exists. Protect by: selling support, updates, and the live service; keeping the best taste data and client work private; using a private repo with a clear licence; selling access, not secrets. A free preview of 3 skills plus a paid full pack is how others do it (see 2a).
- **Licence for what he sells:** use a proprietary "personal/commercial-use, no redistribution" licence file for his own code and skills, plus a THIRD-PARTY-NOTICES file listing every component above with its licence. His own code can be proprietary even though it depends on Apache/MIT parts, as long as their notices are kept.
- **Private repo caution:** a private GitHub repo is not a delivery system. Sharing access means giving the buyer the whole git history (including any key that was ever committed). Before sharing: run a secret scan, make a clean export with no history, and remove client names and renders.

### 3.2 Trademarks and naming

- Anthropic's Trademark Guidelines (effective 2024-08-01): third parties may use Anthropic's marks "only as specifically permitted" and "only in materials we approve beforehand"; permission can be withdrawn; no implying sponsorship or endorsement; no altering the marks; the page does not cover "for Claude" or "powered by" wording and says to email marketing@anthropic.com ([Anthropic](https://www.anthropic.com/legal/trademark-guidelines), fetched 2026-11-07). A tracker quotes the API terms as barring use of the name or logos for other products without written permission ([ConductAtlas](https://conductatlas.com/platform/anthropic/anthropic-api-terms/provision/CA-P-051322/prohibition-on-unauthorized-use-of-anthropic-branding/)) **[UNCERTAIN: not verified against Anthropic's own text]**.
- **Practical rule:** product and brand names must not contain "Claude" or "Anthropic" ("Video Create Studio", not "Claude Video Studio"). Plain factual text such as "works with Claude Code" is the lowest-risk use but is still not formally approved by the guidelines; ask marketing@anthropic.com if it will be a headline. No Claude logo, no "official", "certified", or "by Anthropic" language. The repo's `.claude/skills` folder name is a technical path, not a brand claim.
- Same care for "HyperFrames", "HeyGen", "GSAP", "Remotion", "Pixabay", "Lucide": say "built with / compatible with", never "official".
- Also: the Claude Code plugin names he publishes should not start with "claude" or use the reserved official marketplace names ([marketplace docs](https://code.claude.com/docs/en/plugin-marketplaces)).

### 3.3 Other

- Anthropic usage terms for AI-driven services and selling outputs were not audited here. If he sells videos generated through Claude Code, check the current Commercial/Consumer terms on his own plan **[NOT CHECKED]**.
- Client contracts: AI-generated media can carry SynthID and cannot be guaranteed as copyright-protected everywhere **[UNCERTAIN, general knowledge]**; the contract should say the client gets a licence to the finished video and is told AI voice and music were used.
- Bangladesh-side: payment rails, tax and registration were not researched. His memory notes say he is a school accountant, so he should ask a local accountant about freelance income reporting and a payout route (Payoneer/bank) before the first foreign sale **[NOT RESEARCHED]**.
