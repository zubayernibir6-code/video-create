## ভয়েস বানানোর নিয়ম (সব পর্বে একই)

Google AI Studio → Generate speech (আপনার চেনা পদ্ধতি)।

| সেটিং | মান |
| --- | --- |
| Model | Flash TTS (Audio) |
| Voice | Sadaltager (বিকল্প: Charon, Puck) |
| Temperature | 0.7 |

**মূল স্টাইল প্রম্পট** (লেখার উপরের ঘরে বসান। প্রতিটা পর্বের নিচে একটা ছোট বাড়তি লাইন আছে, সেটা এর শেষে জুড়ে দেবেন):

```
Read this in natural Bangladeshi Bengali (standard Dhaka cholito), like a confident tech creator talking to a friend on Facebook Reels. Fast and clear, about 3 words per second. Say the English tool names clearly in English. Only a 0.3 second pause between sentences, and a slightly longer beat before each "প্রথমটা / দ্বিতীয়টা / তৃতীয়টা / চতুর্থটা / আর পঞ্চমটা" line. A small lift in energy on each tool name. No filler words. Do not sound like a news announcer.
```

- প্রথমবার শুধু হুকের লাইনটা দিয়ে পরীক্ষা করুন। বাংলা উচ্চারণ ঠিক শোনালে তবে পুরোটা।
- স্ক্রিপ্ট হুবহু পড়াতে হবে। একটা শব্দ বদলালে আমাকে জানাবেন, কারণ ক্যাপশন ঠিক এই লেখার সাথে মেলানো হয়।
- ভয়েস একটু ধীর হলে আমি সুর না বদলে ১.১২ গুণ পর্যন্ত দ্রুত করতে পারি।
- ফাইল: WAV বা MP3, যেকোনোটা।
