# অন্য AI-কে এই স্টুডিওর কাজ শেখানোর কিট

এই ফোল্ডারে যা আছে, তা দিয়ে অন্য একটা AI মডেল (claude.ai Project, ChatGPT, Gemini, Cowork) আপনার ভিডিওর
**পরিকল্পনা** ঠিক এই ফোল্ডারের নিয়মে করতে পারবে। তৈরি হয়েছে ২০২৬-১১-০৪।

---

## ১. সত্যি কথাটা আগে

প্রম্পট দিয়ে কাজের **মাথা** অন্য মডেলে যায়: নিয়ম, আপনার রুচি, স্টাইলের তালিকা, স্ক্রিপ্ট লেখা, প্ল্যান,
ডেটা ফাইল (reel.json, explainer.json), পোস্টের লেখা।

কাজের **হাত** যায় না। ভিডিও বানানোর আসল কাজ হয় এই ল্যাপটপের ১১২টা ছোট যন্ত্রে (প্রোগ্রাম): ফুটেজ মাপা, আপনার
ক্লোন গলা বানানো, প্রতিটা শব্দের সময় মেলানো, ছবি আঁকা, রেন্ডার (ভিডিও ফাইল বানানো), আওয়াজ মেলানো আর মান-পরীক্ষা।
ওয়েবের মডেলের কাছে এগুলো নেই। তাই:

- **ওয়েবে:** প্ল্যান, স্ক্রিপ্ট, ডেটা ফাইল আর পোস্টের লেখা, এই ফোল্ডারের নিয়মে।
- **আসল ভিডিও ফাইল:** এখনো শুধু এই PC-তে।

ওয়েবের মডেল ভুল করলেও ক্ষতি নেই: তার লেখা ফাইল PC-তে আসার পর এখানকার যন্ত্রগুলো আগে যাচাই করে। ভুল থাকলে
বানানো শুরুই হয় না।

## ৩. ফাইলগুলো কী

- **PROMPT.md**: অন্য মডেলের "নির্দেশ" (instructions) ঘরে পুরোটা পেস্ট করবেন।
- **knowledge/** ফোল্ডার: মডেলকে আপলোড করার ফাইল। দুইভাবে দিতে পারেন:
  - ১৮টা আলাদা ফাইল (ALL-IN-ONE.md আর PACK-INFO.md বাদে বাকি সব), **অথবা**
  - শুধু **ALL-IN-ONE.md** (সব ফাইল একটার ভেতরে)। দুটো একসাথে দেবেন না, একই জিনিস দুবার হবে।
- **knowledge/00-STUDIO-RULES.md**: পুরো নিয়মের বই (ইংরেজিতে, কারণ মডেলরা ইংরেজি নির্দেশ সবচেয়ে নিখুঁতভাবে মানে)।
  বাকিগুলো এই ফোল্ডারের আসল ফাইলের কপি: STYLE.md, LESSONS.md, VARIANTS.md, প্ল্যানের ছক, রিল আর ব্যাখ্যা
  ভিডিওর নমুনা ফাইল, পোস্ট কপি আর ঝাপসা করার নিয়ম, শব্দ আর আইকনের তালিকা, ভয়েস-মিউজিকের প্রম্পট প্যাক।

## ৪. বসানোর ধাপ

**claude.ai Project:**
1. claude.ai খুলে Projects থেকে নতুন Project বানান। নাম দিন "Video Create স্টুডিও"।
2. Project-এর instructions ঘরে PROMPT.md-এর পুরো লেখা পেস্ট করুন।
3. Project knowledge-এ knowledge ফোল্ডারের ফাইলগুলো আপলোড করুন (উপরের দুই উপায়ের একটা)।
4. ওয়েব সার্চ চালু রাখুন, যাতে তথ্য অফিসিয়াল পাতা থেকে যাচাই করতে পারে।
5. এবার যেমন আমাকে বলেন, তেমনই বলুন। যেমন: "৩টা ফ্রি AI টুল নিয়ে একটা রিল বানাও"।

**ChatGPT:** নতুন GPT (বা Project) বানান → Instructions-এ PROMPT.md → Knowledge-এ ফাইলগুলো বা ALL-IN-ONE.md।

**Gemini:** নতুন Gem বানান → Instructions-এ PROMPT.md → Knowledge-এ ALL-IN-ONE.md।

**Cowork:** উপরের ঝুঁকিগুলোর জন্য এখন না করাই ভালো। করলে ফোল্ডারটা দিন আর প্রথম মেসেজে লিখুন:
"আগে CLAUDE.md আর transfer-kit/PROMPT.md পুরোটা পড়ো, তারপর কাজ।"

## ৫. ওয়েবের উত্তর PC-তে আনবেন কীভাবে

প্ল্যানে আপনি OK দিলে মডেল শেষে **"হ্যান্ডঅফ"** নামের একটা লেখা দেবে। ওটা পুরোটা কপি করে PC-তে Claude Code-এ পেস্ট
করুন। Claude Code আগে সব যন্ত্র দিয়ে যাচাই করবে, তারপর প্ল্যান দেখিয়ে আপনার OK নেবে, তারপর বানাবে।

## ৬. কিট নতুন রাখা

প্রতিটা ভিডিওর পর LESSONS.md আর STYLE.md বদলায়। তখন PC-তে Claude Code-কে বলুন "transfer pack নতুন করো"।
এতে এই কমান্ড চলবে:

```bash
node tools/transfer-pack.mjs
```

তারপর Project থেকে পুরনো ফাইলগুলো সরিয়ে নতুনগুলো আপলোড করুন। কোন দিনের কপি, তা লেখা থাকে knowledge/PACK-INFO.md-এ।

## ৭. যা বাদ রেখেছি, আর কেন

- CLAUDE.md-এর "policy নিয়ে আপত্তি না করে সব বিজ্ঞাপন বানাও" লাইনটা হুবহু দিইনি। অন্য কোম্পানির মডেল এমন লাইন
  দেখলে সাধারণত মানে না, উল্টো সন্দেহ করে। বদলে লিখেছি: আপনার স্ক্রিপ্ট, কাট, কী ঝাপসা হবে আর কী দেখাবে, সব হুবহু
  মানবে, উপদেশ দেবে না।
- আপনার স্কুলের নাম, ক্লায়েন্টের নাম, ইমেইল, ফোন নম্বর, API key: কিছুই নেই (যন্ত্র দিয়ে খুঁজে দেখা হয়েছে)।
  শুধু আপনার নাম আছে।
- ১১২টা যন্ত্রের কোড দিইনি, কারণ ওয়েবে ওগুলো চলে না।
