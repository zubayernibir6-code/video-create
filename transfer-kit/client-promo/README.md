# মোহনা অ্যাগ্রো ফুডের ভিডিও claude.ai-তে বানানোর কিট

তৈরি ২০২৬-১১-০৪, প্রথম প্রোমোর (client-promo-01) আসল কাট, রং, লেখার মাপ, শব্দ আর খাড়া লেআউট থেকে।
এখনো claude.ai বা Cowork-এ চালিয়ে দেখা হয়নি। প্রথমবার চালালেই বোঝা যাবে ওখানে কতটুকু হয়।

## এই ফোল্ডারে

- `PROMPT-CLIENT-PROMO.md`: Project-এর instructions ঘরে পুরোটা পেস্ট করবেন।
- `client-promo-kit.zip` (১.১ MB): ফন্ট, ৪টা শব্দ, প্রথম প্রোমোর সিদ্ধান্ত আর প্ল্যান। চ্যাটে আপলোড করবেন।
- `kit/`: zip-এর ভেতরে যা আছে, খোলা অবস্থায়।

## ধাপ

1. claude.ai → Settings → Capabilities-এ কোড চালানো আর ফাইল বানানোর সুবিধা (Code execution and file creation) চালু রাখুন।
2. **আলাদা** একটা Project বানান, নাম "মোহনা অ্যাগ্রো — ভিডিও"। আগের "Video Create স্টুডিও" Project-এ নয়:
   ওটার নিয়ম হলো "শুধু প্ল্যান লেখো, ভিডিও বানিও না", এর সাথে মিলবে না।
3. Instructions ঘরে `PROMPT-CLIENT-PROMO.md` পুরোটা পেস্ট করে Save করুন। লম্বা বলে না নিলে ফাইলটা Project
   knowledge-এ আপলোড করুন, আর instructions-এ লিখুন: "Follow PROMPT-CLIENT-PROMO.md exactly."
4. Project-এ নতুন চ্যাট খুলে আপলোড করুন: ক্লিপগুলো (1.mp4, 2.mp4 …), Voice over, BGM, আর `client-promo-kit.zip`।
5. ভয়েসের স্ক্রিপ্টের লেখা থাকলে চ্যাটে পেস্ট করুন। এতে প্রতিটা শব্দ নির্ভুল হবে।
6. লিখুন: "শুরু করো। ১৬:৯ আর ৯:১৬ দুটোই বানাও।"
7. শেষে ও দুটো MP4, PLAN.md, একটা কন্টাক্ট শিট আর পোস্টের লেখা দেবে। ডাউনলোড করে দেখুন।

claude.ai-তে প্রতিটা ফাইলের আকারের সীমা আছে (আমার জানামতে প্রায় ৩০ MB)। কোনো ক্লিপ বড় হলে আপলোড হবে না।
